# Link 的共享语义与真实 Gallery 接入

基于全部当前 WIP；本轮由 root 单独修改共享实现。上一轮物理取消验收已通过，证据继续保留在 `design/reviews/link-native-availability-20261020/native/`，不重绑定为本轮语义验收。

## 根因及共享位置

`ContentRole` 和 macOS `AccessibilityRole` 都缺少 Link。Gallery 的 Link 使用独立保留的 LinkView，其节点没有进入公共可访问树；最初回归测试在查找节点时失败（`link-role-20261020/red.log`），不是已存在节点仅角色错误。

公共组合契约新增 `ContentRole::Link`，复用 Button 现有的单动作所有权规则：装饰子项不另发语义节点、不路由独立动作、拒绝交互子项与容器式动态变更。仅把原有角色判断合并成一个私有分类方法，没有新增组件适配器、交互状态机或布局层。

macOS 桥将 Link 映射为 AXLink，使用既有 Press、Focus、禁用和缓存对象失效保护。Gallery 从真实 LinkView 挂载命中区域及当前标签发布 Link，AX Press 经现有 LinkView.activate 执行。独立消费者和 Gallery 的组合语义投影均已补上映射。

## 范围与例外

适用于声明 Link 角色的公共 Component、现有 Gallery Link 以及两处通用语义发布器。没有新增注册组件或扩大整个组件族迁移。普通 Button 继续保留 Button 角色；正文和装饰文字继续保持自己的规则。Link 的绘制、Enter 激活、Space 向父级传播和 URL/业务目标的宿主所有权均未改变。

ContentRole 已带 non_exhaustive，消费者应显式映射 Link，避免通配分支降级成 Group。平台 AccessibilityRole 是可穷举枚举，其新增变体需要外部穷举匹配者迁移。本轮未改写 AgentKit 已冻结或公开的包。

## 分层证据

详见 `design/reviews/link-role-20261020/acceptance.json`。公共控件345项通过，包含 Link 单动作所有权、装饰子项和嵌套交互拒绝回归。Gallery 真实 Link 的角色、单次激活、禁用和失活隔离通过。独立 native example 编译、严格 Clippy 通过。

原生 AX 对象6组检查通过，无应用和窗口：真实 AXLink、Press/Focus 选择器、禁用调用拒绝、缺失节点、替换后的旧对象拒绝、当前对象角色和关闭状态拒绝。启用时真实 Window 事件派发不属于该探针；首次探针调用触发了平台创建窗口前的保护，已保留原日志并修正探针范围。

本轮不把对象检查或 Gallery 自动测试写成外接屏原生窗口、GPU、VoiceOver 听读或整页体验通过。Gold7 的当前范围是复用既有 Link 视觉与交互、单语义动作和生命周期隔离；新角色仍需小宿主原生体验核验。VoiceOver 按用户要求保持关闭。没有性能测试、提交、推送或 Issue 状态操作。
