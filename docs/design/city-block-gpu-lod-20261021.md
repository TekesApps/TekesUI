# 街区 GPU LOD 与物体剔除（2026-10-21）

继续使用 gallery-design-baseline worktree，保留其他未提交改动，复用现有 target。原 GLB 未修改。

## 实现

- 独立的 visibility 模块从 GPU 蒙皮、morph、节点变换输出生成包围盒。静态姿态缓存结果，姿态改变才更新；程序化运动另加保守扩张。
- GPU 按六面视锥和物理像素尺寸筛选、压紧实例，直接写 indirect draw 的实例数量。被移除的对象不再执行绘制阶段顶点着色器。帧循环不读回可见性、不上传实例/顶点，也不因缩放重建 draw bundle。
- 所有网格的策略、输入实例、可见实例和间接参数使用批量缓冲区。每帧只有一次可见性 dispatch，各 primitive 独立调度，避免逐网格提交 compute 带来的 CPU 开销。GPU 包围盒只在姿态改变时刷新。
- 城市种类和阈值留在 district 适配器；通用 Renderer 不识别城市物件名称。透明物件继续使用原排序路径。
- smoothstep 渐变带配合稳定世界空间 stipple 淡出。每实例新增 detail vec4，从 144 B 变成 160 B，仍然只在配置时上传。

|特征|过渡带（物理像素）|远景行为|
|---|---|---|
|窗内人物|12–16|跳过人物距离场，保留入住率、灯色和开关灯|
|窗帘面板|6–8|保留稳定玻璃明暗与灯光|
|窗帘褶皱|20–24|跳过褶皱计算|
|行人|3–6|小于 3 px 移出绘制列表|
|耳机配件|8–12|远景移除配件几何|
|车辆|4–8|小于 4 px 移出绘制列表|
|树木|4–8 消失，8–12 运动|先静止树冠，再移除小实例|
|行人肢体|6–12 运动|小尺寸停止摆动计算|

物件使用经过实例缩放的参考直径及投影比例，属于保守像素估算；窗格用 UV 导数求短轴像素跨度。此版实现特征/实例 LOD 和视锥剔除，尚未自动生成整栋楼或整辆车的低面数替代网格，也未加入遮挡查询。原索引网格、蒙皮、morph 和法线计算保留。

## 验证

新增真实 GPU 回归覆盖平滑/平面法线两条路径：近景 indirect 数量、视锥外对象排除、与原始直接绘制像素一致、阈值区间连续淡出、远景 indirect 数量为零，以及缩放无实例/几何重传、无 bundle 重建。

原有低分辨率室内人物测试改到足够近的视角；午夜离场与手动删除实例的对照使用相同 LOD 策略。

## 原生性能

M4、10 核、32 GiB 统一内存；固定 2960×1362 物理渲染目标、4×MSAA，窗口前后截图均为 3024×1730。两组均开启夜景、街区动画及持续旋转，各请求采样 60 秒；每组复位相机和城市时钟。近景为默认放大约 1.92 倍，鸟瞰为默认缩小约 8.27 倍。

|视角|CPU 均值|CPU 1 秒桶 P95|GPU 帧耗时均值|FPS|进程物理内存（结束）|
|---|---:|---:|---:|---:|---:|
|近景，动画＋旋转|8.92%|12.73%|17.59 ms|59.22|529.20 MiB|
|鸟瞰，动画＋旋转|15.83%|17.00%|6.77 ms|59.92|524.75 MiB|

CPU 100% 代表一个逻辑核。CPU 与轻量 Metal Overview 同时采样；GPU 为目标原生窗口的 GPU Begin to End 帧加权均值，不是整台机器 GPU 利用率。请求记录 60 秒，计数器滚动窗口覆盖近景 60.34 秒、鸟瞰 60.16 秒，两组 CPU 均有完整 60 秒样本，无停止渲染区段。窗口 GPU 活跃比约为 90.9% / 39.2%，同样不代表整机利用率。物理内存是进程统一内存占用，不冒充独立显存峰值。近景仍接近 GPU 帧预算，不保证每帧都在 16.67 ms 内完成。

这是远近视角对比，不能把全部差值归因于 LOD；此轮没有独立的同视角 LOD 开关基线。共享桌面还有其他项目构建，结果不是隔离机器测试。仅 `accepted-near`、`accepted-far` 进入最终报告，其他校准及中间实现记录排除；出现暂停区段或窗口被缩窄到 1514×1730 的采样均未采用。

增加 Animation → Background benchmark (B)，也支持 `--benchmark-background`。仅开启该测试选项时，失焦仍推进时钟及旋转；日常默认关闭，继续失焦暂停并尊重系统减少动态设置。最终两组均开启此选项，未使用菜单保持前台。用户可在另一屏幕使用其他 App，但 3D 窗口必须保持可见、尺寸固定，不能最小化或切走所在桌面；完全遮挡时 macOS 可能停止呈现，不能把这种区段计作持续 GPU 测试。测量完成后已关闭后台测试并恢复默认视角。
