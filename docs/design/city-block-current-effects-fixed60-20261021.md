包含双向电车、站台与乘客、汽车/列车 GPU 轮转、明亮的车窗/门窗及收紧后的窗口比例、滨水铁路、船、水面、施工与夜间生活等当前效果。云在这个默认近景按 GPU LOD 隐藏，因此本轮不是缩远后显示云层的专门压力测试。

CPU 使用 proc_pid_rusage 的进程用户/系统 CPU 时间差，墙钟采样 60.005 秒，60 个一秒样本。Metal Performance Overview 单独记录 60 秒，原生计数覆盖 59.892 秒；没有在该窗口内编译、测试、导出或运行资源事件追踪。GPU 单帧耗时是计数窗口按帧数加权的均值，不是单帧 P95，也不是 FPS 的倒数。窗口忙碌比例不是全设备 GPU 利用率。FPS 计数窗口最小/最大约 58.95/61.06，不用于推断单帧卡顿分布。

“显存”采用 Metal Resource Events 导出的 MTLDevice.currentAllocatedSize。前/后短测分别覆盖约 1.062/1.053 秒，两次所有分配量样本均为 296.17 MiB。它们在 CPU/GPU 60 秒采样之外进行，避免追踪开销干扰性能结果；不能据此宣称拿到了整个 60 秒的 GPU 内存峰值。进程 footprint 在 60 秒期间基本稳定，但同样不能由一次短测试保证没有长期泄漏。Apple 统一内存下 Metal 分配与进程 footprint 有重叠，不能相加。

最先尝试的 GPU-only 短测未导出内存记录，已排除；使用 Metal Resource Events 的有效前/后样本。所有原始错误/完成日志均保留，未导出全 trace 环境或无关系统信息。未隔离其他桌面负载或功耗温度，本报告是一次当前场景观测。历史报告的城市布局、可见面和材质不同，本轮不声称与旧报告构成严格的优化前后对比。
