# Gold7：Design System 七项体验核对基准

记录日期：2026-10-16。用户明确将本轮讨论的七项优点命名为 **Gold7**，供以后设计、实现及验收核对使用。

Gold7 是目标与核对框架，不表示当前产品已经全部实现或通过验收。它记录用户本轮明确认可的方向；附件中的其他操作指令不会因此自动成为项目要求。

| ID | 优点 | 对用户的价值 | 核对规则与观察对象 |
| --- | --- | --- | --- |
| G1 | 温润的人文质感 | 长时间阅读更平静、亲近 | 暖中性色为主，陶土等经过调校的品牌色承担少量强调；在完整页面检查强调色比例、排版、留白与阅读感受，而非只看色卡。 |
| G2 | 四层微对比表面 | 层级清楚，界面安静 | 先用表面明度区分区域，再按需要补细边与阴影；浅色高层允许同色，但须通过位置、轮廓或投影保持层级可辨。 |
| G3 | 发丝细边与精密圆角 | 控件轻巧，嵌套更协调 | 细线随屏幕密度调整，必要边界和焦点仍清晰；圆角按组件角色分配，嵌套按几何关系校准；检查实际倍率下的渲染。 |
| G4 | 经过调校的交互物理 | 操作有响应，移动有连续性 | 按压、展开、吸附分别使用统一动效预设；连续拖动直接跟随指针；减少动态效果有对应降级；检查真实组件的接入与体验。 |
| G5 | 输入与滚动保护 | 减少误操作和阅读中断 | 输入法、建议菜单、手动滚动等用户意图优先；不误发送、不越级关闭、不抢阅读位置；核验草稿恢复和主动返回最新。 |
| G6 | 多模态与桌面交互 | 查看、拖动、分屏更顺手 | 保持缩放及阅读锚点，明确平移/分屏边界、捕获取消与恢复路径；关键动作有键盘或非手势入口。 |
| G7 | 独立组件、文档与预览 | 易理解、复用和调整 | 设计令牌、组件行为、示例、文档和可运行预览共同交付；业务组合不能只用静态示意或 planned 登记冒充实现。 |

## 核对方式

- 每项分别记录 **设计契约、代码接入、实际体验** 三层证据；规范存在、模型测试通过，不等于实际体验通过。
- 结果统一为 **通过 / 失败 / 未测 / 不适用**；不适用须说明平台或产品范围依据。缺实现应在代码层明确记为失败或缺失，不能用“已有规范”抵消。
- 颜色比较设计规律、语义配对、主题变化、叠色及对比度，不比较 HEX 是否相同。OKLCH 生成与透明叠色可以共存；技术机制应服务 Gold7 的最终视觉目标。
- “已有代码/设计选择”不能单独作为偏离 Gold7 的理由。无阴影、按压不缩放、中性焦点等都须根据目标体验重新评估，不作为永久豁免。
- 保留旧/新可比较证据；修改提案与用户已批准默认值区分。命名 Gold7 不自动批准某个新画面，不自动授予发布权限。
- 当前状态必须绑定实际版本及证据，不能把历史测试或本轮静态检查当作将来的实时验收结果。

## 2026-10-17 精修边界

基础表面、正文、默认标签和分隔线保持独立的暖中性体系。消费者给出的红、橙、黄、绿、青、蓝、紫只用于推荐强调色候选，不把整页灰阶染成品牌色。候选 seed 与实际生成的动作底色、配对文字和浅强调色分开展示；消费者确认后才应用。推荐是设计选择，不是某种颜色唯一的数学解。

装饰容器的分隔线与必要控件边界不能混用。普通模式的装饰线按一个设备像素处理；必要控件边界、选中标记和焦点仍须可辨。需同时记录四边像素相位、抗锯齿峰值与积分覆盖；积分相同不等于实际观看时一样清晰。外接屏实看与 GPU 离屏测试分别记录。

Checkbox 的视觉方框与点击行解耦：桌面候选为 16pt 方框、6pt 标签间距、至少 24pt 命中行。单行整体居中，多行对齐第一行中心。标签使用正文/禁用文字语义，不得复用选中勾的 on-accent 颜色。此尺寸是本项目选择，并非附件规定的平台标准。

焦点结构已采纳附件的 2pt 独立外环及 2pt 可见间隔，并保留品牌独立的中性语义；输入编辑焦点、键盘焦点与错误边框分别处理。组件周围的绘制空间、滚动显露和真实祖先裁切仍需逐项验证。浮层没有阴影也须通过同色和复杂背景中的层级可辨性检查；若发生融合，需在共享 elevation 能力中修复，不能逐页补画。

| 动效用途 | 附件参考 | 当前输入 | 核对边界 |
| --- | --- | --- | --- |
| 按压即时反馈 | micro 60ms | press 70ms | 需真实组件接入后比较；10ms 差异本身不足以判失败 |
| 小范围状态吸附 | snap 120ms | geometry 120ms | 数字相同不代表消费者及职责相同 |
| hover / 透明度 / 阴影 | base 200ms | stateChange 150ms | 应按属性区分，不能全局替换一个数字 |
| 面板进入 | sheet 300ms | listExpansion 300ms | 展开与进入不是同一用途 |
| 低频环境转场 | ambient 450ms | expansion 500ms | 两者无直接对应关系 |

`StateTransition` 模型和 Motion 演示不能代替真实控件接入。统一过渡尚未接入真实 Button、Disclosure、浮层时，G4 代码层应记录缺失；需检查连续中断、反向切换、命中位置和 Reduced Motion 后才可确认体验。草稿恢复、主动返回最新、媒体缩放平移等缺口也必须保留，不能用规范条目或静态示意抵消。

机器核对入口为 `scripts/check-gold7.py`，它区分机械检查与评审结论；通过结论须绑定实际源码及证据字节。允许冻结未提交工作树的哈希清单，无需为取得检查通过而提交 WIP。性能工作本轮暂停，120Hz/8.33ms 不由设计检查代替验收。

### 焦点显露、浮层 elevation 与生产动效整改

焦点外延仍为 JSON 的 2pt 环＋2pt 间隔，显露时再保留一个物理像素的 AA 余量。组件本身的动作框不再充当焦点绘制 clip；文字与点击保持原内容可见框，焦点仍受真实祖先 viewport 限制。共享 `ScrollArea::reveal_focus` 用文档坐标显露目标，不通过放大 viewport 假装解决裁切；Menu 的测量、padding、滚动与绘制使用同一内框。

`design/source/layout.json#/elevation` 给 Menu/Popover 绑定 floating、Dialog 绑定 modal；普通 Panel 不加投影。浅深色均为两层，源自附件 DESIGN.md §2.5 的 shadow-sm/shadow-lg，角色分配与 CSS px→logical pt 的 1:1 是本项目的明确映射。blur_radius 采用 [CSS box-shadow 的 Gaussian 语义](https://www.w3.org/TR/css-backgrounds-3/#shadow-blur)，sigma 为半径的一半。渲染器新增独立 ShadowQuad，矩形用 Gaussian CDF 分解，圆角用 24 个横截面积分；不是几圈透明边框。JSON 按 front-to-back 编写，painter 逆序绘制在 surface 后方。shadow-ink 品牌独立，增强对比度关闭阴影并保留必要边界/遮罩。

Button、Switch、Disclosure 的实际接线、时长、失活、Reduced Motion 及后续缺口见 [组件动效接线](component-motion-integration.md#2026-10-17-生产接线)。本轮保持字体、品牌与中性底色，不增加组件，不运行 CPU/120Hz 性能测试。整套 Gold7 的体验状态仍逐项保留，不能把 GPU 像素检查解释为所有显示器/VoiceOver 已验收。


本批的 [源码与验证收据](../../design/reviews/gold7-20261017/alignment-pass2/receipt.json) 保留 743 项 Rust 测试通过、1 项既有可选本地图标测试忽略，以及严格 Clippy、Gallery 构建、纯 Rust、格式、DS、Gold7 23 项检查器回归和静态颜色检查日志。GPU 留下三种生产浮层 × 四主题 × 1×/2× 的 24 张图、真实控件起始/中间/结束帧 4 张及焦点图 8 张。首次整合时发现的 header prepass 与新焦点 gutter 不一致失败也保留，修正测量后重新运行完整检查。

最终 app 与本轮 Cargo 二进制核对一致；原生窗口观察了 Button 激活与左侧 Tab 环、Menu 方向键与投影、Dialog 居中动作与 Escape 焦点恢复、Switch 指针/Space，以及 Disclosure 点击展开/Space 收起。当前 Gallery 停留在 Disclosure。未把这些有限样本扩大为全部组件、所有屏幕、VoiceOver、真实 IME 或完整 Gold7 通过；性能保持暂停。

### 继续整改：浮层生命周期、Split 原生事件与阅读/草稿保护

本批仍为纯 Rust，不新增公开组件或导航入口。浮层停稳后的颜色、字体、尺寸和 JSON elevation 保持原值；`overlay_presence` 使用 JSON 的 150ms 标量透明度过渡，不增加位移或缩放。Menu/Dialog/Popover 关闭时立即结束命中、键盘占用并恢复既有焦点，绘制生命周期单独结束；重开承接当前进度，Reduced Motion 直接到终点。每个退场帧重新生成文字，不能跨帧复用旧 atlas glyph；页面卸载、上下文变化与无效布局清理旧呈现。Select、ComboBox、CommandPalette 继续复用真实 MenuView。

当前透明度逐图元应用，不是独立离屏层合成；背景、文字和阴影叠加的中间帧不等价于整体图层淡出。这是本批明确的渲染边界，静止端点不变；四主题真实 GPU 中间帧单独检查，不据此宣称已实现通用合成层。

Split 的 Gallery 适配必须接收真实 `Left Dragged`，不能用 `Moved` 模拟原生拖动通过测试。捕获中的拖动与释放跨入侧栏仍交给原组件；无按键移动揭示丢失释放时回滚，失活与无效布局取消。分隔条双击、获得焦点后的 Enter/Space 使用同一个均分复位入口。受限窗口与媒体平移的缺口分别保留。

既有 Text/ScrollArea 预览增加真实 Button 操作：`Append paragraph` 只追加确定性段落，`Return to latest` 显式开启跟随。初始仍显示文首；向上滚动、正文交互退出跟随，手动到达底部不会自动开启。追加与容器重排保留 UTF-16 位置及行内偏移；当前夹具是 append-only，不承诺任意替换或前插都能保持身份。阅读策略由应用适配层持有，生产 TextSurface/ScrollArea 不承担业务跟随策略。

既有 Forms & validation 可显式开启持久草稿夹具：启动时设置 `TEKESUI_GALLERY_DRAFT_FIXTURE` 为已有目录下的绝对 JSON 文件路径。默认不持久化，不扫描用户目录。真实输入与勾选写入同一原子快照，包含草稿、不可变 outbox 修订和按修订确认；`Resolve` 控制失败/成功，`Interrupt & recover` 重新打开存储。提交前先保存，旧修订确认不能清掉新输入，marked preedit 不作为已提交草稿保存。此为单写入者、本地模拟 transport，不声称真实网络服务或断电验收；单元测试显式使用临时目录，不受运行环境路径影响。
