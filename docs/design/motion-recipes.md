# Gallery 可交互动画配方

2026-10-16。入口：Gallery → Motion → **Recipes / 配方**。使用现有原生 Rust Scene/CoreText/wgpu 路径和宿主时钟，无新增窗口框架或计时器。

## 四种效果

- **共享元素转场**：同一卡片在摘要与详情几何之间移动，bounds、圆角、内部图形随主轨道变化，详情内容由独立透明度轨道进入。静态边框仅作起点/终点参考，主体只绘制一次。点击收起/展开可在途中反向。
- **多属性面板**：高度/位置、遮罩、内容透明度、内容缩放组合。延迟滑块控制内容轨道起点；幅度控制面板位移，主体时长与阻尼控制弹簧。
- **分阶段成功反馈**：准备 → 处理中 → 成功，进度与勾选图形使用独立轨道。此处按设定时长模拟工作，不连接真实保存操作。取消或暂停都会丢弃旧阶段，旧成功状态不会在稍后触发；展开继续当前值，重播从初态重新演示。
- **保持阅读位置**：向已有列表上方插入或移除内容。左侧不补偿，右侧使用 `scroll = userScroll + presentedInsertionHeight`，补偿与布局使用同一个呈现值。两侧使用同一组内容，“03 · 正在阅读的内容”有高亮，便于看出差异。“向上阅读/向下阅读”模拟用户主动滚动，每次 36pt，优先保留用户偏移。

## 操作与参数

上方四个配方按钮切换场景；**收起 / 取消、暂停、展开 / 继续、重播、演示中途改目标** 均使用页面实际命中路径。演示按钮会在 `阶段延迟 + 主体时长 × 0.45` 后自动反向；手动操作和参数编辑会取消该计划。

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| 主体时长 | 0.15–1.5s，默认 0.5s | 弹簧频率为 1 / duration，透明度/进度 Tween 使用同一时长；不是强制截断弹簧 |
| 阻尼比 | 0.35–1.5，默认 0.85 | 各弹簧轨道；透明度/进度不受其影响 |
| 阶段延迟 | 0–0.6s，默认 0.12s | 面板/共享元素内容轨道和成功阶段的启动延迟；阅读示例不需要延迟，滑块禁用 |
| 幅度 | 16–160pt，默认 72pt | 共享元素圆角变化的基数、面板位移、成功脉冲尺寸、阅读插入高度；具体视觉量按场景缩放 |

暂停保持当前呈现值并停止请求帧；暂停期间改参数仍保持暂停，展开继续。运行中的弹簧调整时长/阻尼保留位置与速度；Tween 保持位置，使用新曲线自身的速度。阅读高度调整会同步重映射当前高度与速度，补偿仍以相同呈现高度计算。Reduce Motion 即时完成当前目标和阶段，关闭后不会自动重播。

## 代码边界

`tekes_ui_motion::recipes::RecipePlayer` 提供四轨求值、可取消的延迟阶段、暂停/继续、参数校验与阅读锚点计算，不拥有 UI 或系统时钟。调用方传入单调 `Duration`。Gallery 负责绘制与输入；已有 Apple / Design System 目录继续保留。

这里的参数均为 TekesUI 实验值。参考来源见 [motion-references.md](motion-references.md)，不代表 Airbnb、Figma、Claude 或 Cursor 的内部规格。本轮是固定 Gallery 场景，尚未把共享 identity 接入任意组件树，也没有实现通用 Keyframe 编辑器或任意文档布局锚点系统。

## 扩展：14 个 Recipes

2026-10-16 新增以下十种，原四种保留：列表增删与重排、Shared Axis 导航、Fade Through 切换、拖拽惯性与吸附、Stagger 交错入场、锚定 Popover、按压反馈分轨、Skeleton → 内容、数字内容转场、顶层页面切换。选择区现在三行，文档高度 858pt，沿用 Gallery 的滚动视口。

通用按钮为：**目标 A / 反向、暂停、目标 B / 展开、重播、演示中途改目标、继续当前**。“继续当前”沿暂停前的目标继续；目标 A/B 则明确改变方向。显式操作取消自动反向计划。对当前场景无作用的参数禁用，避免给出虚假旋钮。

| 新配方 | 场景参数和特殊操作 |
| --- | --- |
| 列表增删重排 | 六个固定 ID，各自有位置轨道；C 淡出、F 淡入并重新排序。幅度调整行距，目标 A/B 在两组顺序间切换。 |
| Shared Axis | 两个步骤沿 X 轴协调移动并淡入淡出，幅度调整距离；快速 A/B 可反向。当前未做 Y/Z 轴选择器。 |
| Fade Through | 内容 A 先淡出，B 再淡入；延迟旋钮在此控制交接比例，幅度调整 B 的缩放。 |
| 拖拽惯性与吸附 | 在预览区直接拖动并松手，五个固定吸附点。使用鼠标采样速度预测目的地，再以弹簧吸附；幅度调整速度投射强度。可在滑行中再次抓取。它是 Gallery 的投射+弹簧演示，不承诺复刻平台完整摩擦积分。 |
| Stagger | 六张卡片依次出现，目标 A 以反向顺序退出；延迟为每项间隔。暂停清除未触发项，继续以当前值恢复到原目标。 |
| Popover | 从固定触发按钮的左上锚点展开，独立内容轨道延后出现。幅度控制位移。 |
| 按压反馈 | 在预览区按下、拖出、拖回、松开，形状弹簧与有界填充效果分轨。也可用目标 A/B 演示。 |
| Skeleton → 内容 | 用延迟模拟数据到达，轮廓占位向真实内容交接；幅度调整亮带宽度。结束后不为 shimmer 保持无限帧请求；不是连接真实网络的加载控件。 |
| 数字内容 | 独立数值轨道从 128 到 `128 + 增量×10`，五位固定数字槽滚动。改增量或反向时从当前数值继续；阻尼和阶段延迟禁用。 |
| 顶层页面 | 固定导航栏与两组工作区内容；内容区域缩放、位移和淡入，延迟调整效果轨道起点。 |

所有新配方默认使用 TekesUI 实验参数，而非声称已逐像素复刻各设计系统。官方来源与 Material 平台参数见 [候选研究](motion-recipe-candidates.md)。

## 斜向文字扫描（第15项）

入口 Recipes → **斜向文字扫描**。文字笔画作为遮罩，柔边亮带沿默认45°方向从左上扫向右下；背景不绘制亮条。多行使用同一投影坐标，扫描会跨行连续移动。

参数：扫描时长0.3–4s（默认1.2s）、扫描方向−75°至75°（默认45°）、启动延迟0–0.6s（默认0.12s）、亮带宽度16–160pt（默认64pt）。角度表示扫描前进方向；亮带与前进方向垂直。A/B反向，暂停/继续当前保留扫描位置，重播重新开始。当前为单次扫描，不默认无限循环；结束后停止请求帧。Reduce Motion 显示静态可读文字。

基础数学为 `recipes::TextScanBand::span`；Gallery 使用1pt行切片和三层柔边，通过现有字形绘制与clip实现，不修改共享renderer或shader。扫描位置连续；改角度和宽度会即时改变亮带形状。切片有有限开销，真实高倍率边缘与全帧性能尚需原生验收，不以数值测试代替视觉检查。

## 旋转组（第16–20项）

- **平面旋转 Z**：矢量卡片在屏幕平面旋转，默认90°，可调15–720°。
- **水平轴翻转 X**：绕横轴上下翻转，带透视，默认180°，可调15–360°。
- **垂直轴翻转 Y**：绕竖轴左右翻转，带透视，默认180°，可调15–360°。
- **加速旋转与刹停**：默认转1080°，可调15–2160°；默认1.8s，慢起步、中段加速、末尾速度和加速度回零。制动偏置−1至1（默认0.2）改变加减速节奏，正值使进程前移、负值后移；不是物理摩擦系数。中途反向保留当前角速度，因此会先继续少量原方向运动再制动转向。
- **旋转回摆落定**：弹簧旋转，默认90°、阻尼比0.45；通过阻尼比较轻微超调与接近无回摆的效果。

旋转组均可调整启动延迟和目标角度，暂停、继续当前、切换A/B、重播；改目标角度会同步重映射当前角度和角速度，避免视觉跳变。除加速刹停外，时长参数控制弹簧频率，非强制截断时间。当前角度/角速度/目标采用度数显示，轨迹图仍为归一化进度。选择区四行，文档高度900pt，沿用滚动视口。

X/Y使用纯数学透视投影，Z使用平面旋转；页面绘制带非对称标记的矢量卡片，未把任意文字、图片或组件子树接入3D变换。为避免共享renderer改动，矢量面使用有界1pt扫描行填充，轴对齐边缘/高倍率视觉和整帧成本仍需原生验收。加速刹停为可打断五次曲线并带单调时间偏置，初始角速度连续，最终角速度/加速度归零；没有无限旋转任务。

## Typing（第21–22项）

新增“定时打字与浮现”和“流式批量文字浮现”，详见 [typing-engine.md](typing-engine.md)。独立的零依赖TypingEngine按时间批量释放完整显示单元，视觉淡入独立。流式示例字速0表示到达即显，正值表示限速平滑；可调淡入、到达间隔、批量，支持换文案取消旧队列。选择区五行，HEIGHT942。当前是固定段落排版/字形簇预览，不是完整生产流Markdown组件。

## 独立 Symbols 分类

另加 **Symbols / 图标** bank，包含 14 个 Apple 官方效果族/变量描绘模式，不增加 Recipes 的 22 项数量，也不改变页面 942pt 高度。复用现有操作，三列比较 Whole / By Layer / Individually；文档与素材能力说明见 [Symbol Effects](symbol-effects.md)。参数为 TekesUI 自定实验值，未声明 Apple 曲线或所有变体逐帧兼容。
