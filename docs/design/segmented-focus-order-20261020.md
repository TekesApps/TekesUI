# SegmentedControl 共享焦点整改（2026-10-20）

基于当前全部 WIP。公共模型及 View 的修复已通过有界 API、真实消费者、GPU 和外接屏原生复验；不代表第5批或全部八批完成。未提交、推送、打 tag 或关闭 Issue；未测性能，VoiceOver 未开启。

## 根因及共享修复

- `extended::SegmentedControl.key` 的 End 从禁用末项向后查找，不能落到最后一个可用项。复用已有反向查找修复；直接模型和实际 View 均有失败前证据。
- `SegmentedControlView` 连续绘制分段，后续不透明背景覆盖前一分段向外伸出的焦点环。复用原 Button painter，最后绘制实际键盘焦点分段；布局／命中结果仍按原始索引保存，不补画第二个环。
- 消费者无法查询真实子项焦点。新增与 `RadioGroupView` 同名的只读 `focused()`，直接返回现有状态，不增加镜像状态或公共协议。
- 外部仅移焦点后，方向键仍使用旧选中项；目标已经选中时还会漏移焦点。沿用 RadioGroup 已有 `key_from` 方式，从实际焦点导航并取消旧 Space 所有者。

共享位置是 controls 的 `extended.rs` 与 `layout_view.rs`。适用于全部已有 SegmentedControl 模型／View 消费者；无需页面补丁。没有新增 token、状态、注册组件、框架或通用抽象层。

合理例外：Tabs 已有焦点显露间隔；RadioGroup 的指示器位于有间隔的行内，且已有焦点查询及导航入口，没有同一遮挡复现；最后一项原先也不会被后续兄弟覆盖。真实祖先裁剪始终优先。槽位／面板组合协议、整库动效及 VoiceOver 听读另行验收。

72个真实 Scene 顺序场景，整改前48例遮挡、整改后0例；布局索引及受控选择保持正确。192帧真实 GPU 检查覆盖96组旧版／新版比较：四主题、三品牌、两尺寸及配对宽度／scale，首项和中间项焦点完整，真实祖先裁剪仍有效。普通／高对比紧凑图及真实外接屏截图分别核对。9组真实 token 探针共4,416个有界场景及治理／组合门禁通过；不声称完整 token 依赖或组件成熟。

最终小宿主 PID82441 在外接屏 U2790B@2 完成16个原生检查点，真实事件区间17–60中无失活中断。验证 Tab、Home／End、禁用与恢复、焦点与选择独立发布、选中值未变时的方向键焦点移动、原生 AX Press、真实主键点击及禁用项隔离。工具驱动原生输入与物理键盘／VoiceOver 听读明确分开。

首次宿主遗漏 lossless Pointer 分发，真实鼠标验收失败，证据保留在 `attempt1-pointer-route-missing`；只修宿主事件接线，补原生 MouseEvent 转换失败／通过回归，重新构建签名并完整复验。中途失活的焦点链也明确拒绝，没有算入最终通过。
