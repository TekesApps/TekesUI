# 街区多视角 tabs 验收（2026-10-21）

顶部提供总览、行人、汽车驾驶、电车驾驶、电车乘客五个 tab；点击、数字 1–5、City viewpoint 菜单均可切换。共用当前城市时间，拖动/方向键转头，滚轮调整视野，空格暂停，R 返回总览并复位。汽车沿既有路线自动行驶，无手动驾驶/碰撞导航。

Scene3D 通用能力：世界坐标 `Camera3D::look_at`、预编译 `RouteSampler3D`、缓存 `Renderer3D::set_blended_emission_scale`。只在 CPU 采样镜头跟随对象的路线，不更新 actor 或顶点；128 字节相机 uniform 继续走既有 wgpu 渲染路径。车内视角关闭透明表面外观发光，保留不透明灯具与建筑照明；总览恢复透明发光。

铁路是有限街区演示。优先跟随仍在可见区间的列车，两列均驶出时在站台候车，重新进入后恢复跟车，不跟随地下隐藏返程。

58 项定向测试通过（Viewer 24、Scene3D 30、组件 4，含真实 GPU 测试），严格 Clippy、模型比例检查通过。回归验证切换 tab 保留时间/暂停状态，不增加几何和实例上传；材质发光倍率切换能精确恢复图像。原生 Release app 已验证点击 tab、数字快捷键、转头、夜间窗外街景，截图保存在验收目录。

验证复用了现有 target 和上轮已提交依赖源码快照，仅覆盖本次 3D 代码、资产和已有健康小屋输入。当前工作区无关 tokens build.rs 引用了尚未导出的 design-export 接口，直接编译工作区失败；未修改该处 WIP，不声称当前全工作区构建通过。本次没有新增 60 秒性能采样。
