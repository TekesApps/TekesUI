# Dialog 调用者身份与真实消费者核验

本轮属于第六批菜单／浮层与容器组合的有界整改，不代表整批或 Issue 已完成。

根因在共享组合契约：`ContentHost` 原先只保留调用者 `ComponentId`，同 ID 替换或卸载后重新挂载会错误继承旧焦点恢复意图。打开前已经禁用的调用者也不应在随后重新启用时获得旧意图。

修复复用 `Content.mount`：打开时仅捕获可聚焦且启用的原调用者及其挂载身份；关闭时验证原挂载仍在，再交给现有焦点路径检查当前可用性。适用于所有 `ContentHost` 管理的 `DialogContent`。重排保留挂载，允许恢复；移除、替换、重新挂载或禁用则不恢复。新的明确激活仍有效。未新增公共协议、token 或抽象层。

真实消费者另有接线缺口：原生示例用“焦点回到调用者”推断 Dialog 关闭，在正确返回空焦点时产生失同步。现直接读取现有 `DialogContent::is_open()`，取消平行布尔状态。

验证分别留证：

- 公共 API：先记录两轮真实失败，再通过 4 个新增回归；controls 总计 359 项通过及严格 Clippy。
- 真实消费者：151 项通过；其中富 Dialog 的六种调用者变化分别覆盖显式关闭和 Escape，共 12 个真实 CoreText 场景。原生示例和最小宿主严格 Clippy 通过。
- 真实 GPU：4 主题、3 品牌、两组宽度／缩放，24 场景、48 帧。对照图显式重建“新按钮被聚焦”的旧结果，不冒充旧二进制截图。GPU 输入身份单独绑定，排除不参与该测试编译的原生示例。
- 外接屏原生：U2790B @2，真实 AppKit 菜单驱动公共生命周期，8 个关闭检查点；正常及重排恢复，替换／重挂载／禁用不恢复，重新启用后新意图有效。真实 AXPress 能再次打开替换后的按钮，验证消费者接线。检查接受区间内实际活动状态；不宣称物理键盘或 VoiceOver 听读。
- Gold7：核对模态作用域、可见焦点与关闭恢复；图像、事件及状态分别保留。不代表全页面统一验收。
- Token：9 份实际探针、4416 个有界样例，`complete=false`，未增加 token。
- 门禁：45 组件组合审计、8 项组合门禁测试、42 项能力治理测试通过。全库能力清单最终状态见独立日志；同时进行的 Scene3D 修改不归入本轮验收。
