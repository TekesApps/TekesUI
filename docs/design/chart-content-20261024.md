## 2. 有限 API 与唯一状态

完整草图见 `api-sketch.rs.txt`，不是可编译承诺。保留一个私有 BarChart 和一个私有 ChartView，不暴露 model_mut，不保存第二份 selected/hover/focus，不新增业务 reducer/selection intent queue。

- `ChartContent::try_new(name, data) -> Result<_, ChartContentError>`：名字及每个 label 必须非空白，所有 value 必须 finite；空 data 合法。重复 label 合法，身份仍是 index。
- `replace_data(data)`：先完整验证再提交；NaN、±Infinity、空白 label、容量/epoch 错误全部原子拒绝，旧数据、selection、hover/focus、布局有效性、mount 和待处理 Host 状态逐字节/行为保持。构造拒绝返回 Err，不产生半个 owner。
- 此严格 Content 输入策略不改旧 `BarChart::new` 对 invalid diagnostic 的宽容契约和原测试。新增原模型 `try_replace_data` 承接 finite 数值验证/提交，Content 在调用前验证名称契约；不能在 wrapper 重建 reducer。原 standalone 宽容构造仍可画有效项、统计 invalid_count。

## 3. 原 View 的共享几何改造

把 ChartView::render 中已有 probe→measure→layout 步骤抽成 **同一原 View** 的 arrange/measure helper；render 使用其结果，Content arrange 也调用它。禁止 Content 复制条宽/基线/标签计算，禁止为 hit 再算一个图。

原 `paint_chart_geometry` 改为接受已解析的共享颜色/同一 ChartGeometry 的内部入口，原公开 Palette convenience paint APIs 保留（默认 canvas），不让 Content 从 scene 反推颜色或几何。新入口与旧 render 共用正文绘制和 `chart_text_frame`。

View 的 invalidate/cancel/current-layout 检查也只实现一次。实现可保留一份只读布局输入快照（datum label + value.to_bits 的精确序列），与当前模型比较，避免 NaN PartialEq、同 revision 的不同 model/clone 和 hash 碰撞；这只是 geometry provenance，不是第二份可变数据模型。窗口/mount、arrange frame/clip/文本测量变化会 invalidation；数据 replacement 即便字节相同也显式 invalidation。wrapper 只通知原 View 边界事件，不自行维护 capture token 或命中矩形。

`ChartViewLayout` 是最近 arrange 的快照，semantic current value 一律从原 model 读取，不从旧 geometry.selected 字段读取。当前布局 accessor 必须能区分 invalidated/visible-none；若保留 legacy layout()，新增 fallible/current 查询，不能把旧快照冒充当前输入几何。

## 4. 父约束、空/窄与 clip

- Chart 是有限二维 fill 内容，没有内在“无限高/无限宽”自然尺寸。Content measure 返回有效父 allocation；不读 label 长度制造超父宽度；Host 的原 clean_size/clean_rect 会把非有限值降到安全零，因此不要声称 ContentHost 返回了一个实际上不存在的 NonFiniteParent 错误。
- direct ChartView 入口继续 finite_bounds guard；Content direct trait measure/arrange 同样遇非有限/负值返回零/不可命中。0×N、N×0、空数据、窄于 inset、文字行高挤空 plot 时都是安全空图，不补假柱、不除零、不把零空间视为无限约束。
- 原 finite ±f64::MAX 归一化与负柱/零柱逻辑复用。zero 的扩展 hit 仍由原 View 负责，不能新造 category slot 点击规则。
- 全部 primitive、glyph 和 focus 必须受 `frame ∩ parent clip` 限制；hit 的扩展 rect 也受该交集。clip 外 selection 不变；clip 内空白不变。窄标签可裁切，完整 label/value 仍在读语义快照中。
- arrange 变更先废除旧布局，成功完成原测量后再发布新布局，不能等待 paint 才更新 hit。paint 不得再次产生与 arrange 不同的命中几何。
- Surface/Theme 变化不 remount，也不重置选择/焦点；需要重新度量时沿原 arrange 更新 current 几何。未知 Surface 的原 validated setter 在变更前拒绝，旧布局/状态保留。

## 3. 原绘制顺序与逐 ink ground 表

原 ChartView label-metrics 路径（本窗口 chart.rs:255–366、536–590；collections_view.rs:2454–2545）：

1. host/container 已提供的 Surface ground **P**；Chart 不自行补父背景。
2. 逐 bar：selected 时先填 plot-height 的 category slot，颜色 **S**=selection/selected.background；然后非空 bar fill **M**=data-plot/rest.marker，并在同一个 Quad 内画 focus/hover border。
3. 所有 bar 后画 baseline **B**=data-plot/rest.boundary；会盖在零线经过的 bar/focus 边缘上。
4. 原 ChartView 再画每 bar 数值 **V**=data-plot/rest.text 与类别文字 **C**=data-category-label/rest.text；最终共同受 frame∩parent clip 约束。
