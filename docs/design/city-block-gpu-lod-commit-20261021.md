# GPU LOD 提交边界与独立验证

本次提交包含 GPU 包围盒、批量实例剔除、间接绘制、像素渐变 LOD、后台性能测试开关及 60 Hz 调度，并包含窗口 LOD 必需的共享窗景、材质和 GPU 光照基础代码。

街区 GLB/配方、模型生成器、建筑与人车细节、生活状态、健康小屋和 Gallery 等其他工作仍保留为未提交改动。Viewer 与 district 使用按功能提取的暂存内容，未将这两个文件中的全部 WIP 一并提交。

暂存树导出到临时源码目录后，复用原 target，通过 `--locked` 独立验证：

- Viewer 7 项、scene3d 普通单元 10 项、公共组件 3 项。
- 显式启用的真实 GPU 单元 12 项、GPU 公共组件 1 项。
- 两 crate 的 `clippy --all-targets -- -D warnings`。

合计 33 项测试通过。测试日志及依赖快照保存在本地验收目录。

`city-block-gpu-lod-20261021.md/json` 的原生性能数据来自完整街区 WIP 场景，并记录了当时的 GLB 和可执行文件哈希；这些数据不能冒充本次提交所含旧版模型素材的单独性能结果。
