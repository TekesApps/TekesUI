# 40 组件 Gallery 展示

本轮目标是补齐设计提案的组件展示，保留现有三页和外壳。完成标准：40 个 registry ID 恰好分组一次；252 个基础状态可通过样本选择器切换；四主题与两倍率快照完整；原三页内容区域不被新增目录改变；短窗口可以滚动到全部样本。

组件展示按八类组织：基础与布局、操作与选择、输入与表单、导航与组织、浮层与对话框、反馈与状态、文档与代码、数据与图表。分组和默认状态在 `design/gallery/catalog.json`；组件名和基础状态从原包 registry 读取，没有再手抄一份状态真源。

这些是纯 Rust 绘制的固定状态样本。状态选择器可以点击，但示例 TextField 不接收文字，示例 Button 不执行操作；loading/indeterminate/scrolling 为可检查的静态帧。不能据此声称 40 个可复用控件、IME、焦点管理或无障碍已完成。组合状态另行验收，本轮仅基础状态。

新增页采用 JSON token 的字体族、字号、行高、颜色和尺寸；原有三页文字绘制路径保持。代码示例采用系统 Menlo 映射到 `mono` 字体族，不携带外部分发字体。

新页支持局部滚动，触控板和滚轮沿用系统事件符号与惯性；Shift＋滚轮横移，左右键横移，Page Up/Down 翻页、Home/End 到首尾。上下键继续切目录页。滚动后的选择器命中使用同一偏移变换。原三页仍为固定校准页。

验收结果（2026-10-15）：

- 通过：工作区 279 个 Rust 测试，其中 Gallery 88 个；严格 Clippy 与格式检查。
- 通过：40 个 ID 恰好分组一次，252 个基础状态均可点击命中；四主题下逐状态绘制、边界和确定性检查通过。状态差异比较只包含预览图元，不让标题或选择器变化冒充样本变化。
- 通过：原三页 × 四主题 × 两倍率的内容区域，与已保存的 proposal1 版本像素一致。目录因增加八页而变化，不包含在此断言中。
- 通过：11 页 × 四主题 × 两倍率共 88 张离屏截图。仓库保存八张新增页浅色 1× 预览，全部截图与本地真实窗口证据路径及哈希见 [verification.json](../../design/reviews/component-gallery/verification.json)。
- 通过：真实 1440×827 pt 窗口的八类切页及代表状态点击、Page Down/Up 滚动，共 17 张窗口截图，20 次重绘，正常退出。另有 1000×720 窗口坐标与滚动后命中测试。
- 通过：原生文字上下往返滚动运行 12 秒；文档 7770 pt、视口 827 pt、速度 1800 pt/s，往返周期约 7.71 秒。测量完成 1442 帧，结束后 5 秒内显示链接回调为 0。这是效果保留的冒烟验证，不是完整性能门禁。
- 通过：纯 Rust 边界、134 文件原包完整性、JSON 及生成投影同步检查。
- 未测：人工触控板手势、真实系统全局快捷键、IME、VoiceOver、全部组合状态和生产控件行为。用户尚未确认新增页面外观。

局部视口目前在场景层裁切字形和矩形，尚未实现通用渲染器 scissor；跨裁切边缘的圆角或边框可能在裁切线出现重建边缘。此实现用于 Gallery 状态样本，不能作为通用 ScrollArea 组件交付。
