### 空闲 CPU 的保留意见

门槛是允许 < 0.1% 的采样噪声，且不得有定时器空转。中位数达标，Redraw 计数也不变，但有两点没有查清，所以不写成“干净通过”：

- 3 次单秒尖峰：其中一次与失焦事件重合，另外两次没有对应事件。
- 1 次每秒 5 次空闲唤醒，持续 60 秒，CPU 读数 0.0%，之后 11 次没有再出现。

建议：在没有其他会话干扰的时候复测；再出现时用 `sample` 抓栈，确认来自本进程还是系统框架。

## 人工检查项

1. 用鼠标拖窗口边框，检查实时缩放：内容不撕裂、不错位、不拉伸，松手后恢复正常。这条路径会打开 presentsWithTransaction，自动测试没有覆盖到。
2. 用鼠标点 Pages 与 Appearance 菜单，并按快捷键 ⌘1 / ⌘2、⌃⌘1 到 ⌃⌘6（原 ⌥⌘D 等已改，见 gallery.md），确认生效，勾选状态正确。
3. 把窗口拖到内建屏（120Hz），确认显示正常。
4. 在系统设置里切换深浅色、开关“增强对比度”，Gallery 在“跟随系统”下应跟着变（增强对比度的变更通知没有自动测）。

## 已知限制与后续

- Gallery 里还没有文字，目录行与列标题用灰条占位，F1 有文字渲染后补上。
- token 是临时占位，等 Design 交付的 tokens.json 生成后替换（F2）。
- ⌘Q 直接退出应用，不经过 CloseRequested。
- 渲染器没有处理 GPU 设备整体丢失，丢失后只返回错误。
- 120Hz 持续渲染（CADisplayLink）只留了接入点，没有实现，等有动画时再做。
- accesskit_macos 仍依赖 objc2 0.5，F6 时再复核。
